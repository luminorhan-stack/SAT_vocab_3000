# SAT 词汇检测系统Pro v2

在原版（[SAT_vocab_3000](https://github.com/luminorhan-stack/SAT_vocab_3000)）基础上的模块化重构 + 功能升级。

## 新增功能

### v2.2（2026-11-18）：桌面端响应式布局

- **≥1024px（lg）自动切换宽屏布局，移动端（<1024px）完全保持原样**，功能、交互、配色零变动
- 主内容区 `max-w-2xl`（672px）→ 桌面 `max-w-6xl`（1152px）
- 导航：移动端底部悬浮胶囊 → 桌面端 header 下方顶部标签栏
- 各页桌面多栏：单元卡 3/4 列网格；过滤开关+CSV 导入并排；看板四区块双栏（记录+薄弱 / 趋势+高危）；计划页左右双栏（概览+今日任务 / 任务列表）；自选双卡并排；掌握页词表+归档双栏；错题卡双列；答题选项双列；词库选择页三卡并排
- 滚动列表（任务列表、词表、归档、看板记录）桌面加高，减少滚动

### v2.1（2026-11-18）

**方案 1：全量数据备份与恢复**
- 看板页「📤 备份 / 📥 恢复」：全部业务数据（登录态、词库选择、自定义词库、错题本、测验记录、掌握状态、计划、进度、答题记录）一键打包 JSON 下载
- 恢复为覆盖式（只写备份中存在的键），校验备份标识，非法文件直接拒绝；换设备 / 清缓存前使用

**方案 2：抽测智能过滤 + 单元进度徽章**
- 词库页新增「抽测智能过滤」开关（默认开启）：抽测与自选检测自动跳过「🟢 已掌握」归档词；练习模式不受影响（保留全量排查能力）
- 单元卡显示「🟢 已掌握数/总数」进度；单元全部归档时卡片变绿并标记「✓ 全部归档」

**方案 3：词级答题记录 + 薄弱点分析看板**
- 每次答题自动记录（按日聚合计数 + 累计错误词频 + 单元级对错统计，存储已压缩）
- 看板新增三区块：①近 30 天学习量趋势（SVG 双色柱：绿=答对、红=答错，悬停看明细）②薄弱单元 TOP5（≥10 题、按错误率排序）③高危词列表（累计答错 ≥3 次，可一键加入错题本）

### v2.0（2026-11-17）

### 1. 艾宾浩斯记忆曲线背词计划
- **计划配置**：可选词书（三大内置 + 自定义 CSV 词库）、每日新词量（5-200）、开始日期
- **任务生成**：按词书单元顺序切分每日新词；新词完成后进入复习链
- **复习调度**：间隔 0/1/2/4/7/15/30 天，学后第 1/2/4/7/15/30 天共 6 轮到期复习；复习链走完自动晋升「已掌握」
- **今日任务**：学习页顶部速览卡（完成率环形图）、计划页「学今日新词 / 复习到期词」按钮、按日任务列表（可前后翻日期，逐词勾选完成状态）

### 2. 三态掌握状态 + 归档（参考 complete the words）
- 单词统一划分 **🔴 未掌握 / 🟡 掌握中 / 🟢 已掌握**
- 切换入口：测试答题后的状态条、任务列表状态胶囊、闪卡正面、错题本卡片、掌握页列表——点击循环或直接点目标状态
- 答题联动：答对至少「掌握中」，答错回落「未掌握」
- **已掌握自动归档**：掌握页默认视图可按状态筛选，独立「📦 已掌握归档」区可展开、可回退状态
- **旧数据兼容**：首次加载时将旧 `sat_wrongs` 错题本单词迁移为「未掌握」；旧 localStorage 键名（`lumi_auth` / `sat_vocab_mode` / `sat_custom_data` / `sat_wrongs` / `exam_logs`）全部沿用，登录态、词库、自定义词库、错题、测验记录无缝保留

## 目录结构

```
SAT_vocab_3000_v2/
├── index.html              # 页面壳：模板 + 脚本加载
├── css/app.css             # 主题（三词库配色）/ 状态胶囊 / 计划卡样式
└── js/
    ├── data/               # 词库数据层
    │   ├── data3000.js     # SAT 3000 词（41 单元 4209 词，原样提取）
    │   ├── data700.js      # 卓越班 700 词（11 单元 778 词）
    │   ├── data1600.js     # 机考核心 1600 词（51 List 1425 词）
    │   └── books.js        # 词书注册表
    ├── core/               # 核心逻辑层（无 UI 依赖，可单测）
    │   ├── ns.js           # 命名空间 + 日期工具
    │   ├── storage.js      # localStorage 封装 + 旧数据迁移
    │   ├── statusStore.js  # 掌握状态管理 + 归档
    │   ├── planStore.js    # 计划配置读写
    │   ├── scheduler.js    # 艾宾浩斯调度 + 任务生成
    │   ├── answerLog.js    # 词级答题记录 + 薄弱点统计（v2.1）
    │   ├── audio.js        # 发音（有道 + 系统语音兜底）
    ├── ui/                 # 视图辅助层
    │   ├── planTab.js      # 计划页视图计算
    │   └── masteryTab.js   # 掌握页视图辅助
    └── app.js              # Vue 主应用（原有功能全量保留 + 新功能集成）
```

> 备份/恢复实现在 `storage.js` 的 `SAT.backup`（导出用 raw 存取，兼容原版裸字符串键与 v2 JSON 键）；抽测过滤在 `app.js` 的 `startTest` / `startCustomTest`；答题记录写入点在 `handleAnswer`。

## 运行

无构建步骤。任选其一：
- 直接双击 `index.html`（file:// 协议可用，数据与发音存 localStorage）
- 本地服务：`python3 -m http.server 8765` → http://localhost:8765

依赖 CDN：Vue 3 + Tailwind CSS（离线时页面样式降级，功能不受影响）。
